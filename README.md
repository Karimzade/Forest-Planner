# رویش — برنامه‌ریز روزانه با React

یک پروژهٔ آموزشی انفرادی برای برنامه‌ریزی ۲۴ ساعت روز با دقت دقیقه، پیگیری فعالیت‌ها و یادگیری لغات، و تشویق کاربر با امتیاز و جایزه.

## اجرا

Node.js نسخهٔ ۲۰٫۱۹ به بالا یا ۲۲٫۱۲ به بالا نصب باشد. در پوشهٔ پروژه:

```sh
npm install
npm run dev
```

آدرس نمایش‌داده‌شده در ترمینال را باز کنید. با دوبار کلیک روی index.html پروژه اجرا نمی‌شود.

```sh
npm test
npm run build
npm run preview
```

## جداسازی فایل‌ها

- `src/main.jsx`: ورودی کوتاه React و Router.
- `src/App.jsx`: دادهٔ مشترک، ذخیره‌سازی، مسیرها و یادآوری.
- `src/DayOverview.jsx`: نمای تصویری ۲۴ ساعت؛ یک خانه برای هر ساعت و یک مربع برای هر دقیقه.
- `src/daySlots.js`: محاسبهٔ زمان‌های آزاد و پُر؛ مستقل از React.
- `src/Daily.jsx`, `TaskForm.jsx`, `WordCard.jsx`, `Progress.jsx`, `Chart.jsx`, `Rewards.jsx`, `Stat.jsx`: کامپوننت‌های کوچک‌تر با مسئولیت مشخص.
- `src/context.jsx`: Context مشترک و نام دسته‌ها/وضعیت‌ها.
- `src/helpers.js`: محاسبه، تاریخ، اعتبارسنجی، تابع reducer، ذخیره‌خوانی و ساخت گزارش؛ JavaScript ساده و مستقل از React.
- `src/RewardCelebration.jsx`: پیام تبریک و نمایش موقت جشن دریافت جایزه.
- `src/celebration.css`: شکل و حرکت برگ‌ها، رنگ‌ها، موقعیت‌ها و حالت کاهش حرکت.
- `src/styles.css`: چیدمان و استایل‌های پایه.
- `src/luxury.css`: طراحی سبز جنگلی و طلایی، تایپوگرافی، کارت‌های عاجی، سایه‌ها، نسخهٔ موبایل و حالت کاهش حرکت.
- `src/assets/forest-landscape.svg`: منظرهٔ برداری جنگل و مه؛ بدون نیاز به عکس یا CDN.
- `index.html`: ظرف اصلی صفحه.
- `LEARNING.fa.md`: راهنمای فارسی برای فهم کد و ارائه.
- `tests/helpers.test.js`: آزمون منطق امتیاز، گزارش و زمان‌ها.

React بر پایهٔ JavaScript است؛ JSX، رویدادها، map و filter هم بخشی از کار روزمرهٔ React هستند. این پروژه از TypeScript، Redux و بک‌اند استفاده نمی‌کند. Vite فقط ابزار اجرا و build است. React Router برای برنامهٔ روز، نمای ساعت‌ها، پیشرفت و امتیاز/جایزه به کار رفته است. HashRouter نسخهٔ مناسب میزبانی استاتیک است؛ همان مفاهیم Routes، Route و لینک‌های بدون بارگذاری مجدد را نشان می‌دهد.

## زبان‌ها

پیش‌فرض اولین اجرا انگلیسی است. در اولین ورود، نام و زبان در یک صفحهٔ خوش‌آمدگویی پرسیده می‌شود. فهرست کشویی با جست‌وجوی نام بومی، نام انگلیسی یا کد، ۱۹۰ گزینهٔ زبان/گونهٔ منطقه‌ای دارد. ترجمهٔ کامل رابط فعلاً برای انگلیسی، آلمانی، ترکی، عربی، اوکراینی و فارسی موجود است. برای گزینه‌های دیگر رابط انگلیسی است و این موضوع کنار انتخاب زبان توضیح داده می‌شود. تاریخ/عدد در صورت پشتیبانی مرورگر، قالب زبان انتخابی را دارد. این فهرست ادعای پوشش تمام زبان‌های زندهٔ جهان را ندارد. انتخاب در همان مرورگر حفظ می‌شود؛ رابط فارسی و عربی راست‌به‌چپ و رابط‌های دیگر چپ‌به‌راست هستند. تاریخ و اعداد نیز با زبان انتخابی نمایش داده می‌شوند. گزارش CSV به زبان انتخاب‌شده صادر می‌شود. نام فعالیت و جایزهٔ کاربر خودکار ترجمه نمی‌شود.

- `src/Welcome.jsx`: فرم نام و زبان در اولین ورود و دکمهٔ ویرایش مشخصات.
- `src/profile.js`: خواندن/ذخیرهٔ نام در همین مرورگر؛ بدون ساخت حساب.
- `src/languages.json`: فهرست مستقل زبان‌ها با نام بومی، نام انگلیسی، کد و جهت نوشتار.
- `src/Language.jsx`: یک Context ساده، انتخاب زبان و ذخیرهٔ ترجیح.
- `src/i18n.js`: ترجمه و قالب‌بندی تاریخ/عدد؛ مستقل از React.
- `src/locales.json`: تمام متن‌ها در شش زبان.
- `src/translation-keys.json`: تطبیق کلیدهای قدیمی برای حفظ داده‌های نسخهٔ فارسی.

برای زبان جدید، یک ردیف به languages.json و ترجمهٔ همان زبان را برای تمام متن‌ها به locales.json اضافه و کد زبان را به translatedLanguages در i18n.js وارد کنید. هیچ سرویس ترجمه یا API خارجی استفاده نمی‌شود.

## امکانات

۱. انتخاب تاریخ، افزودن، ویرایش، حذف و کپی برنامهٔ روز قبل.
۲. بازه‌های زمانی از ۰۰:۰۰ تا ۲۴:۰۰ با دقت دقیقه؛ جلوگیری از تداخل. فعالیت عبوری از نیمه‌شب را به دو فعالیت تقسیم کنید.
۳. وضعیت در انتظار، انجام‌شده (سبز) و انجام‌نشده (قرمز) با متن وضعیت.
۴. جست‌وجوی عنوان در روز انتخاب‌شده یا همهٔ روزها؛ فیلتر وضعیت و دسته‌بندی.
۵. خلاصهٔ روز و دانلود گزارش CSV سازگار با Excel؛ گزارش همیشه برای تاریخ انتخاب‌شده است و همهٔ وضعیت‌ها را دارد، مستقل از فیلتر نمایش.
۶. ثبت و اصلاح تعداد لغات هر تاریخ؛ مجموع کل.
۷. یادآوری داخل صفحه و اعلان اختیاری مرورگر در زمان شروع یا ۵، ۱۰ و ۱۵ دقیقه قبل.
۸. امتیاز هر فعالیت، جایزهٔ انتخابی با حدنصاب، دریافت جایزه و تاریخچه.
۹. ذخیرهٔ محلی خودکار و دانلود پشتیبان JSON. پشتیبان در این نسخه برای نگهداری/بررسی است؛ گزینهٔ واردکردن پشتیبان ساخته نشده است.

## قواعد محاسبه

- درصد تحقق = تعداد فعالیت‌های انجام‌شده تقسیم بر تعداد کل فعالیت‌های روز، ضرب در ۱۰۰ و گردکردن به عدد صحیح. این شاخص وزن زمانی فعالیت‌ها را محاسبه نمی‌کند.
- امتیاز فقط یک بار برای وضعیت انجام‌شده منظور می‌شود. برگشت وضعیت امتیاز را کم می‌کند.
- دریافت جایزه، هزینه را از موجودی کم می‌کند؛ باقی‌مانده حفظ می‌شود. کل امتیاز کسب‌شده جداست.
- حذف یا برگشت فعالیتی که امتیازش قبلاً خرج شده فقط وقتی ممکن است که موجودی برای کسر امتیاز کافی باشد.
- امتیاز فعالیت انجام‌شده تا زمان برگشت وضعیت قابل ویرایش نیست.
- اصلاح تعداد لغات جایگزین عدد همان روز می‌شود و دوباره جمع نمی‌شود.

## محدودیت‌های واقعی

- داده‌ها روی همان مرورگر و همان آدرس ذخیره می‌شوند؛ همگام‌سازی چند دستگاه یا حساب کاربری وجود ندارد. دادهٔ نسخهٔ محلی و نسخهٔ منتشرشده جداست. پاک کردن داده‌های مرورگر موجب حذف اطلاعات می‌شود؛ پشتیبان بگیرید.
- یادآوری به باز بودن برنامه و بیدار بودن دستگاه نیاز دارد. بررسی ساعت هر ۱۰ ثانیه است؛ مرورگرهای پس‌زمینه ممکن است آن را به تأخیر بیندازند. اعلان سیستم به پشتیبانی و اجازهٔ مرورگر نیاز دارد. هشدار داخل صفحه حتی بدون مجوز اعلان کار می‌کند. یادآوری‌های خیلی قدیمی هنگام بازکردن برنامه نمایش داده نمی‌شوند.
- تاریخ ورودی میلادی و بر پایهٔ ساعت محلی دستگاه است؛ تاریخ نمایشی با زبان انتخابی و تقویم میلادی است.
- فونت‌های آنلاین Vazirmatn، Manrope و Cormorant Garamond هستند؛ بدون اینترنت از فونت‌های سیستم و Georgia استفاده می‌شود. بقیهٔ برنامه بعد از build وابستگی اجرایی به CDN ندارد.
- ورود دادهٔ واقعی با صفحهٔ خالی شروع می‌شود؛ هیچ آمار نمونه‌ای به داده‌های شخصی اضافه نشده است.

## ارائهٔ پیشنهادی

هدف و مخاطب (۱ دقیقه)، نمایش برنامه و جست‌وجو (۳ دقیقه)، ثبت لغات و گزارش روزانه (۲ دقیقه)، امتیاز و جایزه و دانلود (۲ دقیقه)، ساختار کامپوننت‌ها و Hookها (۲ دقیقه). محدودیت یادآوری و ذخیرهٔ محلی را هم توضیح دهید. موضوع را پیش از تحویل با استاد هماهنگ کنید.


## نمای ۲۴ ساعته

در برنامهٔ روز، کنار تاریخ روی «24-hour view / نمای ۲۴ ساعته» بزنید. این صفحه بر اساس همان تاریخ و فعالیت‌های ذخیره‌شده، ۲۴ خانهٔ ساعت با مجموع ۱۴۴۰ مربع یک‌دقیقه‌ای نشان می‌دهد. سبز روشن یعنی آزاد و طلایی یعنی برنامه‌ریزی‌شده. با انتخاب هر ساعت، بازه‌های دقیق آزاد و پُر نمایش داده می‌شود. دقیقه‌ها در هر خانه از چپ به راست، سه ردیف ۲۰تایی، خوانده می‌شوند. با انتخاب تاریخ دیگر، آمار و خانه‌ها همان روز را نشان می‌دهند. همهٔ وضعیت‌های فعالیت زمان را اشغال می‌کنند؛ این نما درصد تحقق یا نمودار پیشرفت نیست. ساعت پایان شامل بازه نمی‌شود؛ مثلاً ۹:۰۰ تا ۹:۳۰ دقیقاً ۳۰ دقیقه است.

## جشن دریافت جایزه

بعد از دریافت موفق جایزه، ۳۶ برگ سبز و طلایی از بالای کل صفحه پایین می‌آیند و پیام تبریک با نام جایزه نمایش داده می‌شود. این نمایش بی‌صداست و بعد از حدود ۷٫۵ ثانیه بسته می‌شود. دکمهٔ × و کلید Escape آن را زودتر می‌بندند. انیمیشن مانع کلیک روی برنامه نمی‌شود. برای تنظیم prefers-reduced-motion برگ‌های متحرک حذف و فقط پیام ثابت نمایش داده می‌شود. دریافت ناموفق یا امتیاز ناکافی جشن ایجاد نمی‌کند. هیچ کتابخانهٔ انیمیشن یا صوت اضافه نشده است.

## پیشرفت / Fortschritt

تب Progress دوباره فعال است: نمودار تحقق برنامه از اولین روز تا امروز، نمودار لغات روزانه یا مجموع تجمعی، جدول اعداد روزانه و کارت‌های کل فعالیت‌های انجام‌شده، لغات، امتیاز و جایزه‌ها. روز بدون برنامه درصد ندارد و خط نمودار قطع می‌شود. این بخش با نمای ۲۴ ساعته و جشن دریافت جایزه هم‌زمان در دسترس است.
